# «Курьерская» — PC demo

Браузерная игра о ремонте и апгрейде транспорта курьеров. Рабочая ветка демо: `test`.

## Запуск

Откройте `prototype/start-prototype.cmd` в Windows или выполните `node prototype/server.mjs`, затем перейдите на http://127.0.0.1:4173/.

## Демо

Одна мастерская, электросамокат, четыре 2D-взаимодействия, заказы и сроки, замена модулей, регулировка, снабжение, отказ в оплате, простая прогрессия и сюжетный выбор. Прогресс сохраняется в браузере.

[Подробная инструкция и ограничения](prototype/README.md).

## Публикация

Автопубликация из `test` подготовлена через GitHub Actions. [Настройка GitHub Pages и проверка статуса](prototype/PUBLISHING.md).

## Проверка и сборка

```sh
node --test prototype/tests/game.test.mjs
node prototype/scripts/build-demo.mjs
```

Готовый статический сайт находится в `dist/`. Workflow публикует только браузерные файлы. Экономика и баланс предварительные; это прототип для проверки игрового цикла.
